    连接详情

    Pane 使用指南

    用数据线连接 iPhone，在这台 Windows 电脑上投屏。首次使用请先完成手机设置。

    1

    使用条件

    • 64 位 Windows 10 或 11
    • iOS 或 iPadOS 27 及以上版本可显示实时画面
    • Apple 设备（可从 Microsoft Store 安装）
    • 支持数据传输的 USB 线
    2

    启动中文版

    下载中文版后，双击 Pane.exe。便携版已包含 Python。

    3

    从源码运行（可选）

    python -m handset.server

    安装项目依赖后，在项目根目录运行上面的命令。在浏览器中打开 http://127.0.0.1:8765，并保持终端开启。

    4

    设置 iPhone

    • 用数据线连接并解锁 iPhone
    • 手机询问是否信任这台电脑时，点按信任
    • 打开设置 → 隐私与安全性 → 开发者模式，按提示重启并确认
    • 回到电脑，点击开始投屏。首次连接可能需要挂载开发者映像，请保持手机解锁

    Pane 使用与 Xcode Device Hub 相同的显示通道，通过 USB 或 Wi-Fi 传输真机画面和操控指令。
